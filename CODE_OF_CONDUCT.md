# Code of conduct

This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

- Be kind and assume good faith. Critique code and ideas, not people.
- No harassment, discrimination, or personal attacks. Keep discussions on topic.
- Security reports are welcome and are never treated as hostile (see SECURITY.md).

Maintainers may edit, hide or remove contributions that break these rules and may block repeat offenders. To report a
conduct problem, open a private security advisory on this repository titled "Conduct".
